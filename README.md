# ALRADHY Universal Bridge

Local-first Android and browser device bridge.

Development happens on `feature/v0.1-universal-bridge`; `main` is the protected baseline intended for reviewed merges.

**Security warning (development):** The v0.1 prototype uses local HTTP, which is not encrypted; use only on a trusted Wi-Fi/LAN and never send passwords or personal secrets. TLS, certificate enrollment and browser trust are prerequisites before production deployment.
